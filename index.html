Geral

Troque o modo para revelar os campos SSH, XHTTP ou XRay.

SSH
Proxy (opcional)
Transporte SSH-XHTTP
XHTTP é o transporte do SSH (não usa core Xray). Preencha o endpoint HTTP/2 + SNI/Host/Path — USER/PASS continuam sendo credenciais SSH.
OpenVPN / OpenConnect
O APK Full/Lite OpenVPN lê estes campos pelo Config.json. Você pode colar o perfil `.ovpn` completo ou preencher os campos estruturados.

Se preenchido, ele tem prioridade sobre os campos estruturados abaixo.

Certificados e chaves PEM
WSS / relay HTTP opcional
WireGuard
O APK usa a biblioteca oficial WireGuard. Cole um perfil completo ou preencha a interface e o peer; as chaves ficam no Config JSON.
Lightway Rust
O core Android usa YAML internamente. Cole YAML completo ou preencha o endpoint, autenticação e CA PEM.
XRay

O builder envia este valor como string em pinnedPeerCertSha256. Não use array.

Opções avançadas — Mux, FakeDNS, fragmentação

Se preenchido, este JSON é usado diretamente no campo "xray" do servidor.
